Relabel lives in your menu bar and quietly renames new screenshots and PDFs as you take them. It reads each file and names it on your Mac with Apple's own on-device model.

Download for Mac How to open it

Free and open source. Version 0.1.0 for Apple silicon Macs on macOS 27. Not notarized yet, so see how to open it.

Desktop

Three quiet steps

You take the screenshot like always. By the time you look for it again, it has a name you can search for.

01 · WATCH

Keeps an eye on your folders

Pick where screenshots land and which folders hold PDFs. Relabel only touches those, and only files that are new.

02 · READ

Looks at the file, not just the name

It reads the text with Apple's Vision and shows the picture to the on-device model, so a flight list is a flight list.

03 · NAME

Renames it, and keeps the date

Only the file name changes. Created and modified dates stay put, and every rename can be undone in one click.

Small things that matter

The boring parts are done carefully, because it is renaming your files.

Undo and redo, always

Every rename is in a recent list. Undo it, redo it, or fix the name right there.

Tidy Up a whole folder

Preview new names for a messy Downloads folder first. Nothing changes until you say so.

Learns your style

Rename a few files your way and it starts to follow. That lives on your Mac, and Forget Everything wipes it.

Drop files on it

Drag a file onto the menu bar icon, the panel or the app icon. Or use Open With.

Gets out of the way

Pauses in Low Power Mode, backs off when your Mac runs hot, and says so plainly when it can't name something.

Has a command line

relabel tidy ~/Downloads --dry-run for people who live in the terminal.

Get it running

Relabel is not notarized yet: that needs a paid Apple Developer account. So macOS warns about downloaded copies. Pick whichever way you like.

Apple siliconmacOS 27Apple Intelligence on for best names

1 · Terminal, no warning

Downloads made by curl are not flagged by macOS, so it just opens.

curl -L https://github.com/jashjacob/relabel-macos/releases/latest/download/Relabel-arm64.zip -o /tmp/Relabel.zip && \ mkdir -p ~/Applications && ditto -x -k /tmp/Relabel.zip ~/Applications && \ open ~/Applications/Relabel.app

2 · Download button

  1. Click Download for Mac, unzip, drag Relabel to Applications.
  2. Open it. macOS says it can't check it for malware. Click Done.
  3. Open System Settings, Privacy & Security, scroll down and click Open Anyway next to Relabel.

3 · Build it yourself

git clone https://github.com/jashjacob/relabel-macos.git cd relabel-macos && ./build.sh open ~/Applications/Relabel.app

Needs only Apple's Command Line Tools. Without Apple Intelligence Relabel still works, using basic naming from the text on the file, and it tells you when it does. The download's SHA-256 is on the release page.
