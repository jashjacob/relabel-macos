Three quiet steps

You take the screenshot like always. By the time you look for it again, it has a name you can search for.

01 · WATCH

Keeps an eye on your folders

Pick where screenshots land and which folders hold PDFs. Relabel only touches those, and only files that are new.

02 · READ

Looks at the file, not just the name

It reads the text with Apple's Vision and shows the picture to the on-device model, so a flight list is a flight list.

03 · NAME

Renames it, and keeps the date

Only the file name changes. Created and modified dates stay put, and every rename can be undone in one click.

PDFs get names too

Invoices, contracts, papers and scans all come out of the browser called download (3).pdf. Relabel reads the first pages, and for scans it reads the picture, then names the file after what is in it.

Text PDFs

Reads the real text, ignores junk titles like "Microsoft Word - Document1", and keeps company names and numbers as written.

Scanned PDFs

Pages that are only pictures are read with Apple's Vision first, so a scanned invoice still becomes an invoice with a number.

Your own rule

Add one line of your own, such as "start with the client name", and it is used for PDFs only.

Good questions

Does anything leave my Mac?

No. No accounts, no analytics, no network code. Search the source yourself, the command is above.

What does it need?

An Apple silicon Mac on macOS 27 with Apple Intelligence turned on. Without it, Relabel falls back to simpler naming from the text it finds.

Does it get names wrong?

Sometimes, because the on-device model is small. Flights, hotels, products, invoices and errors are named by plain rules and are the most reliable. Everything is one click to undo.

Does it change dates?

No. Only the file name changes, so created and modified dates stay as they were.

Install in one line

Paste this into Terminal. It downloads Relabel, puts it in your Applications folder and opens it. Because it comes through Terminal, macOS does not show an unidentified developer warning.

Apple silicon · macOS 27 · Apple Intelligence on for best names
curl -L https://github.com/jashjacob/relabel-macos/releases/latest/download/Relabel-arm64.zip -o /tmp/Relabel.zip && \ mkdir -p ~/Applications && ditto -x -k /tmp/Relabel.zip ~/Applications && \ open ~/Applications/Relabel.app

Or build it yourself

git clone https://github.com/jashjacob/relabel-macos.git cd relabel-macos && ./build.sh open ~/Applications/Relabel.app

Remove it

pkill -x Relabel; rm -rf ~/Applications/Relabel.app ~/Library/Application\ Support/Relabel

Building from source needs only Apple's Command Line Tools. Without Apple Intelligence it still works, using basic naming from the text on the file, and it tells you when it does. Checksums are on the release page.
